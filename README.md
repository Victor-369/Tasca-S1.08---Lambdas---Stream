# Lambdas and Streams

This repository contains Java exercises focused on practising lambda expressions and the Stream API.

## Requirements

- Java 25
- Maven

## Project structure

Solutions are organised by level and exercise under `src/main/java`. Tests are under `src/test/java`.

| Exercise | Description |
| --- | --- |
| [Level 1, Exercise 1](src/main/java/com/pruebas/proyecto/nivell1/exercici1/README.md) | Find strings containing the letter `o`. |
| [Level 1, Exercise 2](src/main/java/com/pruebas/proyecto/nivell1/exercici2/README.md) | Find strings containing the letter `o` and more than five letters. |
| [Level 1, Exercise 3](src/main/java/com/pruebas/proyecto/nivell1/exercici3/README.md) | Print the names of the months using a lambda. |
| [Level 1, Exercise 4](src/main/java/com/pruebas/proyecto/nivell1/exercici4/README.md) | Print the names of the months using a method reference. |
| [Level 1, Exercise 5](src/main/java/com/pruebas/proyecto/nivell1/exercici5/README.md) | Define a functional interface that returns and prints the value of pi. |
| [Level 1, Exercise 6](src/main/java/com/pruebas/proyecto/nivell1/exercici6/README.md) | Sort strings by length and place numbers afterwards. |
| [Level 1, Exercise 7](src/main/java/com/pruebas/proyecto/nivell1/exercici7/README.md) | Sort strings by length in reverse order and place numbers afterwards. |
| [Level 1, Exercise 8](src/main/java/com/pruebas/proyecto/nivell1/exercici8/README.md) | Reverse a string using a functional interface and a lambda. |
| [Level 2, Exercise 1](src/main/java/com/pruebas/proyecto/nivell2/exercici1/README.md) | Find first names starting with uppercase `A` and containing exactly three letters. |
| [Level 2, Exercise 2](src/main/java/com/pruebas/proyecto/nivell2/exercici2/README.md) | Prefix even and odd integers and join them into a comma-separated string. |
| [Level 2, Exercise 3](src/main/java/com/pruebas/proyecto/nivell2/exercici3/README.md) | Perform arithmetic operations using a functional interface and a lambda. |
| [Level 2, Exercise 4](src/main/java/com/pruebas/proyecto/nivell2/exercici4/README.md) | Sort a mixed string list, replace letters, and filter numeric strings. |

## Build and test

Compile the project and run its tests with:

```bash
mvn test
```

For details about running an individual solution, see its exercise README.
