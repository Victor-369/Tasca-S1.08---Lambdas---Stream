# Lambdas and Streams

This repository contains Java exercises focused on practising lambda expressions and the Stream API.

## Requirements

- Java 25
- Maven

## Project structure

Solutions are organised by level and exercise under `src/main/java`. Tests are under `src/test/java`.

| Exercise | Description |
| --- | --- |
| [Level 1, Exercise 1](src/main/java/com/pruebas/proyecto/nivell1/exercici1/README.md) | Find strings containing the letter `o`. |
| [Level 1, Exercise 2](src/main/java/com/pruebas/proyecto/nivell1/exercici2/README.md) | Find strings containing the letter `o` and more than five letters. |
| [Level 1, Exercise 3](src/main/java/com/pruebas/proyecto/nivell1/exercici3/README.md) | Print the names of the months using a lambda. |
| [Level 1, Exercise 4](src/main/java/com/pruebas/proyecto/nivell1/exercici4/README.md) | Print the names of the months using a method reference. |
| [Level 1, Exercise 5](src/main/java/com/pruebas/proyecto/nivell1/exercici5/README.md) | Define a functional interface that returns and prints the value of pi. |

## Build and test

Compile the project and run its tests with:

```bash
mvn test
```

For details about running an individual solution, see its exercise README.
